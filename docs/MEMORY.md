# 长期记忆

大肥鱼跨会话记住一小份长期事实：怎么称呼你、稳定偏好、长期要求、项目背景、已定决定和少量近期事件。它不是第二份聊天记录；每次回复只注入一个很短的块，重启后仍在。

## 记什么

- 称呼、语言、回复风格等稳定偏好。
- 非一次性的长期要求，例如“改代码前先给计划”“测试跑 npm test”。
- 长期项目背景、路径、技术栈。
- 已经定下的决定和结论。
- 少量重要近期事件，一行一条。

不记：一次性任务、临时状态、寒暄、密钥、密码、令牌、身份证号。写入前有本地正则拦截；命中的内容会直接拒绝。

## 存储与上限

文件是数据目录的 `work-memory.json`：

```json
{
  "version": 1,
  "items": [
    { "id": "m-...", "section": "identity", "text": "称呼 RK；大肥鱼自称本鱼", "pinned": true }
  ],
  "blocked": ["不要记 API key"]
}
```

分组：`identity`（称呼）、`preferences`（偏好）、`longTerm`（长期要求）、`projects`（项目）、`decisions`（决定）、`episodes`（近期）。

- 最多 40 条，每条最多 160 字。
- 注入块最多 4 KB；超出时先删最旧的非 pinned 近期事件，再删最旧的其他非 pinned 条目。
- pinned 条目由用户说“记住”或界面“重要”产生，整理时不会自动删；分组满且全是 pinned 时会拒绝继续添加，并提示先删一条。
- 同一句话重复保存只保留一条；`forget` 可把话题加入 `blocked`，整理器以后不会自动加回。

## 注入位置

`generateReply` 的 system 消息顺序：

1. 角色人设
2. 能力说明（覆盖人设里“只有番茄钟/没有长期记忆”的过时说法）
3. 时间说明
4. **长期记忆块**（稳定前缀，利于 DeepSeek 前缀缓存）
5. 本次 instruction / 工具说明
6. 历史对话
7. 当前用户消息

记忆为空时不发这条 system 消息。任务快照以后放在历史之后，避免每轮变化破坏缓存。

## 工具

前台回复里提供三个已预授权工具：

- `memory_list`：读取已保存记忆，回答“你记得我什么”。
- `memory_save`：`section` + `text` + 可选 `pinned`。
- `memory_forget`：按 id 或内容片段删除；可选 `block` 把话题加入禁止列表。

工具只在官方 DeepSeek 地址下提供（沿用现有函数调用限制）。本地校验分组、长度、密钥模式和上限；失败返回 `{ ok: false, error }`，不抛到会话层。

## 自动整理

每个完成的用户轮次把 `turnsSince` 加一。满足以下条件时，后台用大肥鱼账户跑一次很小的整理请求：

- 已经累计 8 个轮次；
- 距最后一次回复至少 2 分钟；
- 30 分钟内没有尝试过；
- 当前没有前台回复或后台回复在跑；
- 工作台设置里“自动整理长期记忆”开启。

整理请求只带当前记忆（每条带 id，供 update/remove 使用）和最近 12 个完成轮次（各截断），要求模型输出 JSON diff：

```json
{"add":[{"section":"preferences","text":"回复先给结论"}],"update":[{"id":"m-...","text":"..."}],"remove":["m-..."],"blocked":["..."]}
```

本地解析、校验、去重、限额后原子应用；失败不会破坏旧记忆，30 分钟后才会再试。手动“立即整理”可以忽略轮次与间隔，但仍要求账户可用且当前没有回复在跑。

## 从历史初始化

工作台记忆页的“从历史初始化”会把最近 24 个完成轮次交给同一个整理提示词，生成第一份记忆。它是手动操作，不会在启动时静默执行；生成后可在页面里逐条编辑、删除或取消重要。

## 界面

独立工作台的“记忆”页显示：当前条数 / 40、注入块大小 / 4 KB、按分组排列的条目、重要标记、编辑、忘掉、立即整理、从历史初始化、清空。清空和初始化需要再点一次确认。

## 接口

- `GET /api/workbench/memory`：条目、分组、预算和整理状态。
- `POST /api/workbench/memory`：`{ action: "save" | "update" | "forget" | "clear", ... }`。
- `POST /api/workbench/memory/consolidate`：立即整理。
- `POST /api/workbench/memory/import`：从现有聊天历史初始化。

## 隐私

记忆只存在本机；只有作为对话上下文发给大肥鱼账户时才会离开本机，和普通聊天一致。它不包含任务正文、密钥或完整聊天记录。
